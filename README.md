# Solarhub Technology — Website

Next.js + React site for Solarhub Technology Ltd., rebuilt from the Modernist design system.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
- `npm run lint` — ESLint

## Pages

| Route | Content |
| --- | --- |
| `/` | Full landing (hero, model, services, flagship, FAQ, contact) |
| `/about` | About Solarhub |
| `/model` | Business model |
| `/services` | Services + delivery process |
| `/flagship` | Khulna Shipyard flagship + pipeline |
| `/group` | Group companies + industries |
| `/faq` | FAQ accordion |
| `/contact` | Contact details + assessment form |
